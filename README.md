# Daily Projects Streak

A 30-day (extendable) streak of **useful, complete** projects — one pushed to GitHub every single day.

Each day produces its **own repository**: working code, a full README, installation/usage instructions, and a clearly documented **future scope**.

This repo is the living **index** of the whole streak: the roadmap, the daily tracker, and the reusable project template.

## The Rules

1. One working, self-contained project every day — no throwaway "hello world" commits.
2. Every project lives in its **own GitHub repo**.
3. Every repo has: working code + `README.md` + `.gitignore` + `LICENSE` + dependency manifest + (where helpful) screenshots.
4. Every README documents: what it is, why, how to run, features, and **future scope**.
5. Progress is logged daily in [`TRACKER.md`](TRACKER.md).

## Roadmap (rotating focus)

| Phase | Focus | Days |
|-------|-------|------|
| Week 1 | Python automation & tools | 1–7 |
| Week 2 | Web development (JS/Node) | 8–14 |
| Week 3 | Data science & machine learning | 15–21 |
| Week 4 | System / shell / git tooling + capstone | 22–30 |
